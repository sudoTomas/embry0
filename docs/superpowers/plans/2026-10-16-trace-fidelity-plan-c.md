# Trace fidelity plan C: the frontend adopts the event contract

> **For agentic workers:** this plan is executed in waves of parallel implementers, one git worktree per task (`tfc-tN`, branch `tfc/tN` from `feat/trace-fidelity-c`); the controller rebases and fast-forwards each wave and runs the gates. Steps use checkbox (`- [ ]`) syntax for tracking. An implementer reads only its own task plus the header sections above the tasks.

**Goal:** the dashboard reads the event contract the backend now emits (plans A #56 and B #60) instead of the shapes it used to guess at, with render tests from recorded fixtures, and every dead reducer and phantom event type gone. Issue #41; also closes #62.

**Architecture:** `frontend/src/lib/types/events.ts` already carries the 32 contract interfaces, the `ContractEvent` union and `EVENT_FIELDS` with two compile-time guards tying the interfaces to `docs/contracts/events.json`. Plan C makes that union the only one (`LogEvent = ContractEvent`), deletes `events-discriminated.ts` and every `case` on a type nothing emits, and moves legacy-row handling out of the reducers into one normalizer applied where a parsed JSON object first becomes a `LogEvent` (the WebSocket `onmessage` and the REST page fetch). Reducers then read contract names only. Fixtures are generated by a committed Python script from the backend constructors and graph builders, pinned to the contract by a backend test, and loaded by vitest through the existing `?raw` import pattern.

**Tech Stack:** React 18, TypeScript (`tsc -b`), vitest 5 + @testing-library/react 16 + jest-dom, react-virtuoso 4.18 (`VirtuosoMockContext` in tests), Python 3.12 for the fixture script and its test.

**Spec:** `docs/superpowers/specs/2026-10-15-trace-fidelity-design.md`, sections 3.8 (frontend adoption), 5 (frontend hook tests, component render tests), 6 (legacy rows). Sections 3.1 and 3.5 describe the fields the reducers read.

## Global Constraints

- No new npm or Python dependency.
- No backend contract change: `docs/contracts/events.json`, `embry0/execution/events.py` and `EVENT_FIELDS` are not edited. A contract interface may narrow a value type (`graph: PipelineGraph`) but may not gain or lose a key; the `Missing`/`Extra` guards in `events.ts` fail `tsc -b` otherwise.
- No API route changes. The REST events endpoint returns the parsed payload plus `event_seq` and nothing else (no `event_type`, `run_id` or `node` columns), so legacy rows are recognised by payload shape.
- Frontend gates after every task: `npx tsc -b` clean; `npm run lint` with 0 errors and exactly the 4 pre-existing `react-refresh/only-export-components` warnings (`AuthGate.tsx:41`, `JobAdvancedFields.tsx:20,29`, `Button.tsx:51`), no new ones; `npx vitest run` all green; `npm run build` succeeds. Shared helpers go in `.ts` files, never exported from a `.tsx` component file (that adds a fifth warning).
- Every new test is shown failing first (RED) with its own assertion message, then passing; a test that deletes a phantom-type test lists the deletion in its commit body.
- Commits: Conventional Commits, subject at most 72 characters, no AI co-author footer, last line `Claude-Session: https://claude.ai/code/session_011MYiGJuebTGdHFAS8GWusQ`.
- Nothing in this tree names a customer, host, person, cost or real job id; fixture data is synthetic (`job-fixture-*`, `run-fixture-*`, `example.test` hosts).
- "Honesty fixes, no redesign": no new visual components, no restyle; existing components learn to read the real fields and stop rendering fields that do not exist.

## Decisions

Where the spec, issue #41 and the tree at 429ea449 disagree, these rulings apply. The spec sentences they amend are listed in Task 8.

1. **Fixtures are synthesized, not captured.** Spec 5 asks for fixtures "captured from a real run after this change and scrubbed". No deployment is reachable from the development machine and no recorded event data exists anywhere in the tree. `scripts/job_event_fixtures.py` builds one fixture per job kind from the backend constructors (`embry0/execution/events.py`) and the graph builders (`build_pipeline_graph`, `onboard_pipeline_graph`, `qa_pipeline_graph`), stamps `job_id`, `timestamp`, `event_seq` and `prev_seq` the way the orchestrator and the REST route do, and a backend test pins every fixture event to `docs/contracts/events.json` and the files to the script's output. A capture from a real run can replace them after deploy without changing any test. Cost if wrong: a fixture that is contract-true but unlike real traffic hides a rendering bug the contract allows; mitigated by exercising every optional field and the legacy rows.

2. **Legacy rows are normalized once, at the wire.** Issue #41 says to drop the `summary ?? input` and `tool_id ?? tool_use_id` fallbacks and keep `message ?? error` for `error`. Pre-contract `tool_call` rows carry a string `input` and no `summary`, so dropping the fallback in the reducers would blank every old job's tool-call summary line. Ruling: `normalizeWireEvent` in `frontend/src/lib/wire.ts` maps legacy shapes to contract names (`error.error` to `message`, string `input` to `summary`, `tool_use_id` to `tool_id`, `node_id` to `node`, unknown or `raw` types to `system`) at the two places a parsed object becomes a `LogEvent`; the reducers read contract names only. The `message ?? error` fallback does not exist today anywhere in the frontend; it is added, in the normalizer. Cost if wrong: a legacy shape the normalizer does not know renders as a `system` line with its JSON, visible rather than silent.

3. **The interrupt "TTL fallback" is the dead `paused_at`/`ttl_hours` plumbing.** The contract's `interrupt` carries `reason`, `questions` and `summary` (a dict with `message`, `reason`, `pr_url`, `retry_count`, `options`, `latest_review` or `review_error`) and no TTL. `useAgentStates` reads `retry_count`, `latest_review`, `options`, `paused_at` and `ttl_hours` at the top level, so all five are always undefined, and `NeedsYouCard`'s `interrupt` prop with its `useTtlCountdown(paused_at, ttl_hours)` is never passed in production (only its tests pass it). Ruling: `InterruptData` is built from `interrupt.reason`, `questions` and `summary.*`; `paused_at`/`ttl_hours` leave `InterruptData`; `NeedsYouCard` loses the `interrupt` prop and the countdown. `PausedBanner`'s countdown from the job row (`finished_at || started_at`, 48 h default) is job-row based, not event based, and stays.

4. **Agent states are keyed by `run_id`, grouped by `node`.** One `AgentState` per run (`runId`, `node`, `attempt`); a retry of a node is a second card, not a replacement, so earlier attempts' tool calls stay visible. Legacy events with no `run_id` attach to the most recent state for their `node` (today's behaviour); events with neither are not attached to any card, as today. `useAgentStates(events, jobStatus?, graph?)`: pending nodes come from `deriveNodeStates(graph, events, jobStatus)` (state `pending` or `ready`), never from a literal list; with no graph there are no pending cards.

5. **Totals are sums.** `cost_update.cost_usd` is the run's cost delta (plan B adds it to `jobs.total_cost_usd`), one per run. Job cost = sum of every `cost_update.cost_usd` + sum of `turn_usage.cost_usd` for runs that have no `cost_update` yet (in-flight partial; `null` counts as 0). Tokens likewise (`tokens_in`/`tokens_out`, `input_tokens`/`output_tokens`). Turns = sum over runs of the highest top-level `turn_start.turn_number`. Legacy rows without `run_id` form one pseudo-run. One reducer, `frontend/src/lib/eventTotals.ts`, used by `useJobLogs` and `useLiveJobSummary`.

6. **The node filter goes through the graph.** The selected id on the logs page is a graph node id; events carry the LangGraph node (`review` for a `reviewer` graph node, `generic_agent` for research/analysis/ops steps). `filterEventsForNode(graph, events, selectedNodeId)` keeps events whose `node` equals the selected graph node's `physical_node` (plus `qa_*` events for the `qa` physical) and always keeps job-level events (any event with no `node`). Two graph nodes sharing one physical node show the same events; attributing them by run order is a redesign and out of scope.

7. **TracesTable is already contract-correct** (plan A: result values and colors `success/error/running`, agent options from `GET /agents`). Only its render test is left.

8. **`subtask_status` leaves `QA_EVENT_TYPES`**: it is published only on the QA SSE bus, never on the job stream.

9. **Three adjacent defects are fixed in passing** (#62): `partial` is a terminal status (one shared `TERMINAL_JOB_STATUSES` in `frontend/src/lib/jobStatus.ts`), `JobLogsPage` uses that set for "finished", `AgentCard`'s literal `✓` becomes a check mark.

10. **Dead code deleted:** `events-discriminated.ts`; every phantom `case`; `pendingInputs`, `autoAnsweredInputIds`, `nodeStates` and `feedbackStates` from `useJobLogs` and their consumers; `AwaitingInputCard`'s `pendingInputs` prop and its question-event fallback block; `InputForm` (its only caller was the dead pending-inputs block); `ConversationView`'s `conversation_message` handling and `agent_started.prompt` initial prompt; `useAgentStates`' `pipeline_stage_*`, `awaiting_input`, `tool_start`/`tool_end` branches; `PipelineGraphView`'s `feedbackStates` edge highlighting.

11. **View-model types move, they are not deleted.** `NodeStateEvent` is the per-node derived state `deriveNodeStates` produces; it becomes `NodeLiveState` in `frontend/src/lib/pipeline-live.ts` without a `type` field. The `Conversation*Block` types move into `ConversationView.tsx`. `getNodeId` becomes `eventNode(event)` in `frontend/src/lib/wire.ts` (reads `node` only; the normalizer has already mapped `node_id`).

12. **Subagent calls nest under their parent.** `ToolCallEntry` gains `children: ToolCallEntry[]` and `subagent?: { name: string; is_error?: boolean }`. A `tool_call` with `parent_tool_use_id` nests under the entry whose `tool_id` equals it, within the run; `subagent_start`/`subagent_end` (whose `tool_id` is the parent Task call id) fill `subagent`. A child whose parent is unknown (lost to a bus overflow) is kept at the top level, never dropped.

13. **`prUrl` comes from `pr_created`**, the only event that carries it.

14. **`LogEvent` stays the exported name** of the one union (`export type LogEvent = ContractEvent`): twenty files import it, and renaming them is churn, not honesty. `PipelineGraphContract.graph` is narrowed to `PipelineGraph`, `InterruptContract.summary` to `InterruptSummary`; key sets unchanged.

15. **Run boundaries in ConversationView.** Turns are numbered by `turn_number` within a run; when `run_id` changes a divider line (`Run N · <node> · <agent>`) separates the runs. The running cross-run counter goes.

`frontend/src/lib/wire.ts`:

```ts
import type { LogEvent, ContractEventType } from "@/lib/types/events";
import { EVENT_FIELDS } from "@/lib/types/events";

/** Field names pre-contract rows used (spec section 6). Never part of the contract interfaces. */
interface LegacyWire {
  error?: unknown;
  input?: unknown;
  tool_use_id?: unknown;
  node_id?: unknown;
}

const KNOWN_TYPES = new Set<string>(Object.keys(EVENT_FIELDS));

function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);
}

/**
 * Where a parsed JSON object becomes a LogEvent (WebSocket onmessage, REST page).
 * Rows written before the contract are mapped to contract names here, once, so
 * reducers never read a legacy field: `error.error` -> `message`, a string
 * `input` -> `summary`, `tool_use_id` -> `tool_id`, `node_id` -> `node`. A row the
 * API could not decode (`{"type":"raw"}`) and any type outside the contract become
 * a `system` event carrying the text, so they stay visible instead of vanishing.
 */
export function normalizeWireEvent(raw: unknown): LogEvent {
  if (!isRecord(raw) || typeof raw.type !== "string") {
    return { type: "system", message: typeof raw === "string" ? raw : JSON.stringify(raw), timestamp: "" };
  }
  const { error, input, tool_use_id, node_id, ...rest } = raw as Record<string, unknown> & LegacyWire;
  const ev: Record<string, unknown> = { ...rest };

  if (typeof node_id === "string" && typeof ev.node !== "string") ev.node = node_id;
  if (ev.type === "error") {
    if (typeof ev.message !== "string") ev.message = typeof error === "string" ? error : JSON.stringify(error ?? "");
  }
  if (ev.type === "tool_call" && typeof ev.summary !== "string") {
    ev.summary = typeof input === "string" ? input : "";
  }
  if (ev.type === "tool_result" && typeof ev.tool_id !== "string" && typeof tool_use_id === "string") {
    ev.tool_id = tool_use_id;
  }
  if (typeof ev.timestamp !== "string") ev.timestamp = "";

  if (ev.type === "raw") {
    return { type: "system", message: String(ev.message ?? ""), timestamp: "", ...(typeof ev.event_seq === "number" ? { event_seq: ev.event_seq } : {}) };
  }
  if (!KNOWN_TYPES.has(ev.type as string)) {
    const seq = typeof ev.event_seq === "number" ? { event_seq: ev.event_seq } : {};
    return { type: "system", message: `[${String(ev.type)}] ${JSON.stringify(ev)}`, timestamp: String(ev.timestamp), ...seq };
  }
  return ev as unknown as Extract<LogEvent, { type: ContractEventType }>;
}

/** The LangGraph node an event belongs to; "" for job-level events. */
export function eventNode(event: LogEvent): string {
  return typeof event.node === "string" ? event.node : "";
}
```

Run with no arguments to rewrite the files; --check exits 1 when they differ.
"""

from __future__ import annotations

import argparse
import json
import sys
from datetime import UTC, datetime, timedelta
from pathlib import Path
from typing import Any

from embry0.workflows.issue_to_pr.plan_route import build_pipeline_graph

OUT_DIR = Path(__file__).resolve().parents[1] / "tests" / "fixtures" / "job-events"
EPOCH = datetime(2026, 1, 1, tzinfo=UTC)
FIRST_SEQ = 1000
SEQ_STEP = 3  # event_seq is job_logs.id, shared by every job: never contiguous for one job


class Stream:
    """Stamps job_id, timestamp, event_seq and prev_seq the way the orchestrator and the API do."""

    def __init__(self, job_id: str) -> None:
        self.job_id = job_id
        self.events: list[dict[str, Any]] = []
        self._seq = FIRST_SEQ
        self._prev: int | None = None

    def add(self, event: dict[str, Any]) -> dict[str, Any]:
        stamped = {**event, "job_id": self.job_id}
        stamped["timestamp"] = (EPOCH + timedelta(seconds=len(self.events))).isoformat().replace("+00:00", "Z")
        if self._prev is not None:
            stamped["prev_seq"] = self._prev
        stamped["event_seq"] = self._seq
        self._prev = self._seq
        self._seq += SEQ_STEP
        self.events.append(stamped)
        return stamped

import type { LogEvent } from "@/lib/types";

export interface Totals { costUsd: number; tokensIn: number; tokensOut: number; turns: number; runsInFlight: number }

interface RunTotals {
  settled?: { cost: number; tokensIn: number; tokensOut: number };
  partialCost: number;
  partialIn: number;
  partialOut: number;
  maxTurn: number;
}

export interface TotalsState { runs: Map<string, RunTotals> }

export const emptyTotals = (): TotalsState => ({ runs: new Map() });

const runOf = (e: LogEvent) => (typeof e.run_id === "string" ? e.run_id : "");

const getRun = (state: TotalsState, id: string): RunTotals => {
  let r = state.runs.get(id);
  if (!r) { r = { partialCost: 0, partialIn: 0, partialOut: 0, maxTurn: 0 }; state.runs.set(id, r); }
  return r;
};

/** Mutates and returns `state`; callers that need immutability copy the Map first. */
export function applyTotals(state: TotalsState, event: LogEvent): TotalsState {
  switch (event.type) {
    case "cost_update": {
      const r = getRun(state, runOf(event));
      const prev = r.settled ?? { cost: 0, tokensIn: 0, tokensOut: 0 };
      r.settled = { cost: prev.cost + event.cost_usd, tokensIn: prev.tokensIn + event.tokens_in, tokensOut: prev.tokensOut + event.tokens_out };
      return state;
    }
    case "turn_usage": {
      const r = getRun(state, runOf(event));
      r.partialCost += event.cost_usd ?? 0;
      r.partialIn += event.input_tokens;
      r.partialOut += event.output_tokens;
      return state;
    }
    case "turn_start": {
      const r = getRun(state, runOf(event));
      if (event.turn_number > r.maxTurn) r.maxTurn = event.turn_number;
      return state;
    }
    default:
      return state;
  }
}

export function totalsOf(state: TotalsState): Totals {
  const out: Totals = { costUsd: 0, tokensIn: 0, tokensOut: 0, turns: 0, runsInFlight: 0 };
  for (const r of state.runs.values()) {
    if (r.settled) { out.costUsd += r.settled.cost; out.tokensIn += r.settled.tokensIn; out.tokensOut += r.settled.tokensOut; }
    else if (r.partialIn || r.partialOut || r.partialCost) { out.costUsd += r.partialCost; out.tokensIn += r.partialIn; out.tokensOut += r.partialOut; out.runsInFlight += 1; }
    out.turns += r.maxTurn;
  }
  return out;
}

export function reduceTotals(events: readonly LogEvent[]): Totals {
  const state = emptyTotals();
  for (const e of events) applyTotals(state, e);
  return totalsOf(state);
}
